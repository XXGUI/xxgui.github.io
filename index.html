📚 新手引导流程

STEP-BY-STEP GUIDE // NEW USER TUTORIAL

📋前置条件 (Prerequisites)

  • 硬件要求: 搭载了骁龙或者天玑处理器的安卓手机 x 1。
  • 软件准备: 辅助瞄准助手 APK 安装包（以下通称"助手"）。
  • 核心要素: 一个聪明的人。

📱第一步：安装应用 (Installation)

  • 手机打开文件管理找到助手 APK 安装包。
  • 点击 APK 安装包进行安装，如果提示风险请无视风险安装。
  • 安装完成后，点击助手 APP 图标打开应用。

🔐第二步：权限授权 (Permission Authorization)

目标：确保所有 5 个权限图标都显示为绿色（已授权状态）

权限状态说明：
  • 🟢 绿色图标 = 权限已授权 ✓
  • 🔴 红色图标 = 权限未授权 ✗

操作步骤：

  1. 首次打开 APP 时，系统会自动弹出权限申请窗口，全部点击"允许"。
  2. 进入主界面后，查看顶部"APP权限状态"区域的 5 个权限图标：
    • 文件访问 - 需要文件读写权限
    • 悬浮窗 - 需要悬浮窗显示权限
    • 无线调试 - 需要无线调试权限（稍后配对）
    • 截屏 - 需要屏幕录制权限
    • 触摸 - 需要模拟触摸权限（稍后激活）
  3. 如果有红色图标，点击右上角的"点击授权"按钮。
  4. 系统会弹出权限设置页面，按照提示完成授权：
    • 文件访问权限： 在设置中找到"所有文件访问权限"，开启
    • 悬浮窗权限： 在设置中找到"显示在其他应用的上层"，开启
    • 截屏权限： 会弹出"允许辅助瞄准助手录制或投射内容？"，必须点击"立即开始"（会弹出 2 次，都要允许）
  5. 授权完成后返回 APP，确认所有权限图标都变成绿色。
  6. 如果仍有红色图标，重复步骤 3-5，直到全部变绿。
⚠️ 重要提示：
  • 截屏权限会弹出 2 次，两次都必须点击"立即开始"，否则无法正常使用。
  • 如果权限授权失败，可以退出 APP 重新打开，或手动进入系统设置中开启对应权限。

📡第三步：无线配对 (Wireless Pairing)

目标：完成无线调试配对，使"无线调试"权限图标变绿

操作步骤：

  1. 确认"文件访问"和"悬浮窗"权限已授权（绿色图标）。
  2. 打开手机的【设置】→【关于手机】，连续点击 7 次"版本号"开启开发者模式。
  3. 返回设置，找到【开发者选项】并进入。
  4. 在开发者选项中，找到并开启【无线调试】开关。
  5. 点击【无线调试】选项进入详情页。
  6. 点击【使用配对码配对设备】，系统会弹出配对码和端口号。
    ⚠️ 关键提示：
    • 配对码是 6 位数字
    • 端口号是 5 位数字
    • 必须记住弹窗里显示的端口和配对码，不要记无线调试页面列表里的端口
    • 弹窗可能会自动关闭，建议使用小窗或分屏操作，防止切后台导致端口号刷新
  7. 在助手 APP 中，点击"无线激活"按钮。
  8. 选择配对方式：
    方式 A（推荐）： 点击"配对码"，等待通知栏弹出配对码输入框，输入 6 位配对码后点击纸飞机提交
    方式 B： 点击"端口&配对码"，手动输入格式：端口-配对码（例如：12345-123456）
  9. 配对成功后，系统弹窗会自动关闭，无线调试页面下方会多出一个已配对设备。
  10. 返回助手 APP，确认"无线调试"权限图标已变成绿色。
💡 其他激活方式：
  • 如果使用电脑激活，在电脑上执行命令：adb tcpip 5555
  • 如果使用 Root/Shizuku/黑域，也需要执行：adb tcpip 5555
  • 点击"其他激活"按钮可查看详细说明

👆第四步：触摸服务激活 (Touch Service Activation)

目标：完成触摸服务初始化，使"触摸"权限图标变绿

操作步骤：

  1. 确认"无线调试"权限图标已变绿（配对成功）。
  2. 在助手 APP 主界面，查看"触摸设备"区域，确认选择了"ADB触摸"（默认选项）。
  3. 查看"adb连接状态"文字提示，等待显示"触摸初始化完成"（绿色文字）。
  4. 在等待过程中，系统可能会弹出 2 次"是否要授权 USB 调用"的提示，全部点击"允许"。
  5. 等待约 10 秒左右，直到看到绿色的"触摸初始化完成"提示。
  6. 点击"测试滑动"按钮，如果系统自动下拉通知栏，说明触摸功能正常。
  7. 确认"触摸"权限图标已变成绿色。
⚠️ 故障排查：
  • 如果触摸初始化失败，检查无线调试是否已配对成功
  • 如果"测试滑动"无反应，尝试退出 APP 重新打开
  • 如果"触摸"图标一直是红色，检查是否所有权限都已授权

🤖第五步：导入模型（可选）(Model Import - Optional)

说明：如果使用"找色"模式，可以跳过此步骤。如果使用 YOLO V5 或 V8，需要导入模型。

操作步骤：

  1. 在助手 APP 主界面顶部，选择推理框架：
    • V5 - 使用 YOLO V5 模型
    • V8 - 使用 YOLO V8 模型
    • 找色 - 使用颜色识别（无需模型）
  2. 如果选择了 V5 或 V8，点击"添加模型"按钮。
  3. 选择模型 zip 压缩包（包含 .bin、.param、.class 三个文件）。
  4. 等待模型导入完成，模型会显示在列表中。
  5. 点击模型列表中的模型名称选择要使用的模型。

🚀第六步：输入卡密并启动 (Enter License & Start)

目标：输入卡密，点击"开始"按钮启动辅助功能

操作步骤：

  1. 确认所有 5 个权限图标都是绿色：
    ✓ 文件访问 ✓ 悬浮窗 ✓ 无线调试 ✓ 截屏 ✓ 触摸
  2. 如果使用 YOLO 模型，确认已导入并选择了模型。
  3. 在底部"登录卡密"输入框中，输入你的卡密（如果已保存会自动填充）。
  4. 点击"开始"按钮。
  5. 系统会再次弹出截屏权限确认（如果之前未完全授权），点击"立即开始"。
  6. 启动成功后，左上角会出现悬浮图标，表示辅助功能已启动。
  7. 进入游戏后，悬浮图标会自动移动到右边，点击图标可以打开设置菜单。
✅ 启动成功标志：
  • 左上角出现悬浮图标
  • 进入游戏后图标自动移动到右边
  • 点击图标可以打开设置菜单

✅快速检查清单 (Quick Checklist)

在点击"开始"之前，请确认以下所有项目都已完成：

✓ 权限授权检查：
  • 文件访问权限图标 = 🟢 绿色
  • 悬浮窗权限图标 = 🟢 绿色
  • 无线调试权限图标 = 🟢 绿色
  • 截屏权限图标 = 🟢 绿色
  • 触摸权限图标 = 🟢 绿色
✓ 无线配对检查：
  • 已开启开发者选项
  • 已开启无线调试
  • 已成功配对（无线调试图标变绿）
  • adb连接状态显示"触摸初始化完成"
✓ 触摸服务检查：
  • 触摸权限图标 = 🟢 绿色
  • "测试滑动"功能正常（能下拉通知栏）
✓ 模型检查（如使用 YOLO）：
  • 已导入模型 zip 文件
  • 模型列表中已选择要使用的模型
✓ 卡密检查：
  • 已输入有效的卡密
⚠️ 如果"开始"按钮无法点击：
  • 检查是否有权限图标是红色（未授权）
  • 检查无线调试是否已配对成功
  • 检查触摸服务是否已初始化完成
  • 检查是否已输入卡密
  • 如果使用 YOLO 模型，检查是否已导入模型

📡 无线配对与激活

WIRELESS PAIRING // ACTIVATION

再次打开助手后，你需要完成无线配对。以下提供 3 种方式（推荐方案 A）。

方案 A: 电脑激活 (推荐/最稳定)

  • 电脑解压 adb 压缩包。
  • 打开 cmd 窗口，执行 cd 命令进入这个压缩包目录。
  • 执行命令：adb tcpip 5555
  • 出现 “restarting in TCP mode port: 5555” 就代表激活成功。

方案 B: APP 内部配对

  • 打开系统【开发者选项】。
  • 找到【无线调试】选项，点击开启并进入详情页。
  • 点击【使用配对码配对】，页面会弹出配对码和端口。
    注意：要记住弹窗里的配对码和端口，不要记无线调试页面列表里的那个端口。
  • 防刷新技巧: 使用小窗开启助手 APP，或分屏操作。防止切后台导致端口号刷新。
  • 在助手 APP 输入对应的端口和配对码，点击【无线配对】。
  • 配对成功后，系统弹窗会自动关闭，下方会多出一个已配对设备。

触摸初始化

  • 退出助手 APP 重新打开。
  • 会弹出 2 次系统弹窗提示“是否要授权 USB 调用”，点击允许。
  • 等待 10 秒左右，直到页面提示绿色的“触摸初始化完成”。
  • 点击【测试滑动】按钮，测试触摸是否正常。

🚀 启动流程

LAUNCH // MODEL LOADING

📦导入模型

  • 完成无线配对且触摸初始化完成后，点击右上角的【添加模型】。
  • 导入自定义的 zip 压缩包，包内需包含 3 个文件：
    - xxx.bin
    - xxx.param
    - xxx.class
  • 如果模型已存在，可跳过此步。

🔐权限授权与启动

  • 点击【点击授权】按钮进行权限检测授权。
  • 系统会弹出“允许辅助瞄准助手录制或投射内容？”的提示，弹出 2 次都要点击允许。
  • 点击【开始】按钮，左上角出现悬浮图标代表启动成功。

🎮游戏内操作

  • 进入游戏后，悬浮图标会自动切换到右边。
  • 点击图标打开菜单继续设置参数。
  • 点击空白处关闭菜单（此时可能会卡顿 1-3 秒加载模型，属正常现象）。

⚙️ 基础功能菜单

MENU OPTIONS // BASIC

🤖模型与框架选择

  • 推理模型: 下拉框选择你要玩的游戏模型。收起菜单时会加载该模型。
  • YOLO V5: 选择 YOLO V5 推理框架（需要导入对应模型）。
  • YOLO V8: 选择 YOLO V8 推理框架（需要导入对应模型）。
  • 找色模式: 使用颜色识别，无需模型文件。需要配置 HSV 颜色参数。
  • 找色游戏类型: 选择 FPS 或 MOBA 模式（仅找色模式可见）。

👁️显示设置

  • 基础信息: 开启后，左上角显示耗时、当前帧率、平均帧率。
  • 全屏识别: 识别全屏。关闭后屏幕中间显示红色正方形，仅识别该区域。
  • 显示类名: 显示目标类别名称（不建议开，干扰视线）。
  • 显示方框: 显示识别到的目标方框（不建议开，干扰视线）。
  • 显示骨骼: 显示骨骼点（部分模型支持，默认隐藏）。
  • 显示轮廓: 显示轮廓（部分模型支持，默认隐藏）。
  • 显示记牌器: 显示记牌器功能（仅棋牌游戏模式可见）。

🔧其他功能

  • 保存图片: 开启后，识别到目标时自动保存截图到 /sdcard/yoloSave/。
  • 搜索参数: 通过分享码搜索并应用他人分享的参数配置。
  • 分享参数: 生成分享码，将当前参数配置分享给他人（10分钟内只能上传一次）。
  • 重置参数: 将所有参数恢复为默认值（会先备份当前配置）。
  • 退出程序: 结束程序运行。

🎯 自动瞄准配置

AUTO AIM // CONFIGURATION

🎯瞄准开关与坐标

  • 自动瞄准: 开启后会自动瞄准到目标。
  • 获取屏幕坐标: 点击后收起菜单，进入坐标选择模式。长按拖动设置瞄准点，如果开启随机触摸点可双指缩放调整范围。按钮前显示当前坐标 (x,y)。
  • 开启随机触摸点: 开启后，在设置的触摸点范围内随机选择瞄准位置，避免被检测。需要配合触摸点范围使用。
  • 触摸点范围: 当开启随机触摸点时，设置随机范围的大小（像素）。
  • 瞄准速度: 调整瞄准速度滑块，值越大瞄准越快（仅 FPS 模式可见）。

↔️PID 参数 (X 轴)

  • KP_X (比例系数): 调整 X 轴瞄准速度。值越大瞄准越快，但可能产生抖动。默认值: 0.02
  • KI_X (积分系数): 消除 X 轴静差，防抖动。默认值: 0.00
  • KD_X (微分系数): 抑制 X 轴过冲，防抖动。默认值: 0.1
  • MA_X (最大移动距离): X 轴单次最大移动像素值。限制单次移动幅度，防止移动过大。默认值: 5

↕️PID 参数 (Y 轴)

  • KP_Y (比例系数): 调整 Y 轴瞄准速度。值越大瞄准越快，但可能产生抖动。默认值: 0.02
  • KI_Y (积分系数): 消除 Y 轴静差，防抖动。默认值: 0.00
  • KD_Y (微分系数): 抑制 Y 轴过冲，防抖动。默认值: 0.1
  • MA_Y (最大移动距离): Y 轴单次最大移动像素值。限制单次移动幅度，防止移动过大。默认值: 5

📍偏移设置

  • 左右偏移: 瞄准目标向左右偏移的像素值，0 代表不偏移。正数向右，负数向左。
  • 上下偏移: 瞄准目标向上下偏移的像素值，0 代表不偏移。正数向下，负数向上。
  • 偏移单位 - 固定值: 无论距离多远，都偏移固定的 px 值。适合近距离固定偏移。
  • 偏移单位 - 百分比: 动态偏移。根据目标方框大小自动计算，目标越远偏移越小。适合需要根据距离调整的场景。

⚡高级参数

  • 自动调整参数: 开启后，系统会根据实际情况自动调整 PID 参数。关闭后可手动调整。
  • 保存 PID 配置: 当自动调整参数开启时，点击此按钮保存当前自动调整的参数并关闭自动调整。
  • 补偿强度: 触摸补偿强度，默认值: 16384。一般不需要修改。
  • 保存补偿强度: 重置补偿强度为默认值。

🔫 自动扳机配置

AUTO TRIGGER // FIRE CONTROL

🎮开火模式

  • 关闭自动开火: 关闭自动开火功能。
  • 连续点击: 快速连续点击开火键（连发模式按下时长: 5ms）。
  • 连续三连发: 三连发模式（连发模式按下时长: 300ms）。

📍开火坐标与范围

  • 获取屏幕开火坐标: 点击后收起菜单，进入坐标选择模式。长按拖动设置开火键的触摸点坐标。按钮前显示当前坐标 (x,y)。
  • 中心点开火范围: 当目标中心进入该范围时触发开火（屏幕中心会有红色小方框显示范围）。默认值: 10 像素。
  • 目标方框范围比例: 目标方框需要覆盖多少比例才触发开火。范围 0.0-1.0，默认值: 0.8（即目标方框 80% 在范围内才开火）。

⏱️开火速度与延迟

  • 点射间隔速度 (扫射点射速度): 识别到目标后循环触发开火的时间间隔 (ms)。默认值: 150ms。
    例如设置为 118，则每 118ms 自动按一次开火。
  • 扳机延迟开火: 识别到目标后延迟多少毫秒才开始开火。默认值: 100ms。
  • 连发模式按下时长: 每次开火按键按下的持续时间（ms）。连续点击模式: 5ms，三连发模式: 300ms。

🔽压枪功能 (仅 FPS 模式)

  • 开启压枪: 开启后，在扫射时自动向下压枪以抵消后坐力。
  • 扫射压枪倍率: 压枪的强度倍率。值越大压枪幅度越大。默认值: 0.0（关闭）。
  • 设置手动开火区域: 设置手动开火区域。开启压枪后，只有手指按在这个区域内才会触发压枪。长按拖动调整区域，双指缩放调整大小。
  • 手动开火区域显示: 显示当前手动开火区域的中心坐标 (x, y)。

🔧 其他参数与算法

ADVANCED // ALGORITHM

📐识别范围设置

  • 识别范围: (仅 FPS 模式，关闭全屏识别时可见) 设置中心识别区域的大小（像素）。默认值: 325。
  • 识别范围倍数: (MOBA/棋牌模式) 设置识别范围相对于屏幕的倍数。范围 0.0-1.0，默认值: 0.7（即屏幕的 70%）。
  • 识别速度: 每次识别之间的延迟时间（ms）。值越大识别越慢，但可以降低 CPU 占用。默认值: 1ms。

🎯识别精度参数

  • 置信度 (合格率): 识别目标的可信度阈值。范围 0-100，数值越小，误识别概率越高，但能识别更多目标。默认值: 70。
  • 去重叠 (NMS 阈值): 非极大值抑制阈值，用于去除重叠的识别框。范围 0.0-1.0，值越小去重叠越严格。默认值: 0.01。
  • 图像尺寸 (targetSize): 输入模型的图像尺寸。值越大识别精度越高，但速度越慢。默认值: 256。

🏷️类名识别设置

  • 识别类名: 多选框选择要识别的目标类别（如只识别头部或身体，或同时识别）。勾选的类名才会被识别。
  • 编辑类名: 点击进入编辑模式，可以修改类名的显示名称。再次点击保存修改。
  • 独立的类名参数配置: 开启后，可以为每个类名单独配置偏移参数。每个类名可以设置独立的左右偏移和上下偏移。
  • 类名配置容器: 当开启独立的类名参数配置时，会显示每个类名的配置项，包括启用开关和偏移参数。

🎨找色模式参数 (仅找色模式)

  • 启用找色: 在模型推理的同时进行颜色识别（仅 YOLO 模式可见）。
  • 颜色选择器按钮: 打开颜色选择器，在屏幕上选择要识别的颜色。
  • 颜色 H 最小值/最大值: 色相 (Hue) 范围，0-180。默认最小值: 0，最大值: 10。
  • 颜色 S 最小值/最大值: 饱和度 (Saturation) 范围，0-255。默认最小值: 80，最大值: 255。
  • 颜色 V 最小值/最大值: 明度 (Value) 范围，0-255。默认最小值: 80，最大值: 255。
  • 颜色最小尺寸: 颜色块最小尺寸阈值（像素），小于该宽或高的颜色块将被忽略。默认值: 10。
  • 颜色预览块: 实时显示当前 HSV 参数对应的颜色。

👆手动触发识别 (仅 FPS 模式)

  • 手动触发识别: 开启后，只有手指按在指定区域时才会触发识别和瞄准。
  • 设置识别触发区域: 设置手动触发识别的区域。长按拖动调整区域位置，双指缩放调整区域大小。
  • 手动触发识别区域 X/Y: 触发区域的中心坐标。
  • 手动触发识别区域半径: 触发区域的半径（像素）。默认值: 200。

🧮瞄准算法说明

本助手采用 “靠近准星优先 + PID 控制器” 算法。

  • 目标选择: 优先锁定距离准星最近的目标。
  • 移动控制: 使用 PID 算法进行平滑移动，分为 X 轴和 Y 轴独立控制。
  • PID 原理:
    - P (比例): 根据误差大小调整移动速度
    - I (积分): 消除长期误差（静差）
    - D (微分): 抑制过冲和抖动
  • 注意事项: 可能会出现“瞄不准”、“抖动”或“在两个目标间来回切换”的情况，需要根据实际情况调整 PID 参数和偏移值。

💡参数调优建议

  • 瞄准抖动: 减小 KP 值，增大 KD 值，减小 MA 值。
  • 瞄准过慢: 增大 KP 值，增大 MA 值。
  • 瞄不准: 调整偏移值，或使用百分比偏移模式。
  • 误识别: 增大置信度值，增大去重叠值。
  • 识别慢: 减小图像尺寸，增大识别速度值。
  • 开火不灵敏: 减小中心点开火范围，减小目标方框范围比例。

一、登录与初始化

  1. 启动应用后进入登录页，输入卡密完成在线校验（见 LoginActivity）。若本地已有上次登录信息，可能显示「正在初始化验证…」并自动尝试登录。
  2. 校验通过前无法使用需联网授权的功能；网络异常时请稍后重试或检查卡密是否有效。
登录通过后进入主界面（MainActivity），底部为四个 Tab：ADB、模型、外设、教程。

二、资源包：下载、校验与手动导入

大型 assets / jniLibs 可从 APK 中拆出，通过云端清单分项下载或手动导入，由 OfflineResourceManager 管理。

2.1 校验顺序与前置条件

  • 须先成功获取 cpu.json（设备/芯片信息相关清单入口）。
  • 若工程内配置了远程资源清单 URL，还须成功获取 resources.json，再与本地对比缺失项。
  • 界面文案说明：「须先成功获取 cpu.json；若已配置远程资源清单 URL，还须成功获取 resources.json，之后才会校验并下载资源包。」

2.2 界面状态说明

  • 正在校验资源包…：正在校验 cpu.json / 远程清单 / 本地缺口，尚未进入分项下载进度。
  • 正在加载清单：清单加载中。
  • 清单与缺口：若远程清单暂未就绪，可能「暂按内置项校验」，成功加载 resources.json 后会追加本机 HTP Skel/Stub 等项。
  • 分项下载：多文件并行下载（并发上限 5）；列表中可见「下载中 / 等待下载 / 已存在 / 下载完成」等状态及字节大小。
  • 停止下载：用户停止后未完成的项标记为「未下载·已暂停」，可再次「开始下载」或「重试」。
  • 远程清单在应用私有目录中有缓存，超过约 24 小时 后下次启动会重新请求。

2.3 手动导入 .xxg

「手动导入」会选择文件：实为 zip 包，扩展名为 .xxg，根目录需包含 assets/ 与 jniLibs/。导入过程在后台线程执行，完成后会刷新资源状态。

2.4 与「模型」页的关系

仅当资源包就绪（代码中 offlineResourceReadyForModels）后，「模型」页才会显示添加本地模型与本地模型列表。否则会提示先完成资源包；若 Tab 切换时资源未就绪，可能 Toast「资源包还没加载完成」。

若未在 OfflineResourceConstants 中配置 REMOTE_MANIFEST_URL 或 BUNDLE_URL，在线下载入口会提示需先配置地址。

四、模型页：本地与在线模型

4.1 添加本地模型

点击添加本地模型，通过系统文件选择器选择 .onnx 文件；文件会纳入应用管理的模型目录（与 XXGAIConfig.MODEL_DIR 一致，默认 /sdcard/.xxgai/model）。

4.2 本地模型卡片操作

  • 点击卡片主体：打开底部弹窗「模型参数配置」（见下一节），编辑展示名称、精度、类名、关联应用等。
  • 向左滑动卡片：露出右侧「删除」区域，滑到足够位置后点击红色区域可删除该本地模型。
  • 启动 / 停止：卡片右侧按钮。若当前模型已激活且识别运行中，显示「停止」；否则为「启动」。短时间去重（约 200ms）防连点。启动时会激活该模型并走开始屏幕识别流程（需已授权录屏、悬浮窗等）。

4.3 在线模型

列表由远程配置拉取；加载中显示「正在加载在线模型」。失败或为空时提示「在线模型加载失败」或「暂无在线模型」。

单张卡片上点击下载：按 URL 下载到模型目录；若文件已存在且非空则跳过网络直接视为完成。下载完成后会尝试拉取封面图标并写入该模型的手动配置。

已与本地文件名（不区分大小写）相同的在线项不再显示在在线列表中，避免重复下载。

五、主界面「模型参数配置」说明

对应数据结构 XXGAIConfig.ModelManualConfig，用于列表展示与启动关联应用，与悬浮层推理参数（ModelOverlayConfig）分开存储。

字段含义与注意
模型名称列表中显示名称，默认可与文件名相关。
输入尺寸展示用；保存时若填写则须为 32 的倍数，否则会 Toast「输入尺寸必须是32的倍数」并无法保存。
显示图标可从文件选择图片；也可使用资源名或模型目录下图标文件（与图标解析逻辑一致）。
模型精度展示标签（如 FP16），供卡片详情行展示。
游戏类型如 FPS / MOBA 等，影响卡片角标颜色与展示。
关联应用选择本机已安装应用（包名 + 名称）；若授予「查询所有应用」类权限，列表更完整。
启动应用开关：为开且已选关联应用时，从模型页「启动」识别流程中可自动打开该应用（见代码中 autoOpenApp）。
识别类名多行类名，用于界面展示与悬浮层「识别目标」等；与模型输出类别对应时需与训练标注一致。

底部确定写入配置；取消关闭不保存。

六、config.json 与模型高级参数

根目录默认 /sdcard/.xxgai/config.json。模型元数据键为 modelManualConfigs；悬浮窗/推理相关键为 modelOverlayConfigs，键均为归一化后的模型文件绝对路径（避免同一路径不同写法导致配置分裂）。

6.1 推理与 ONNX（ModelOverlayConfig）

下列项多数可在悬浮窗「模型参数」二级面板中调整一部分；其余需直接编辑 JSON 或在后续版本 UI 中暴露。

字段/概念说明
modelInputSize模型输入空间尺寸（如 640）；与 letterbox 缩放相关。
onnxInputLayoutAUTO / NCHW / NHWC。推断错误时请手动指定。
onnxInputChannelOrderRGB 或 BGR（常见于 OpenCV 导出）。
onnxOutputName检测头输出节点名；多输出模型务必填写，避免误用非检测张量。
onnxOutputLayoutAUTO / NC(ROWS) / CN(CHANNELS) 等，描述 rank-3 检测输出语义。
onnxYoloVariantAUTO / V5 / V8 等，对应 YOLO 检测头列语义。
captureMaxLongEdgePx截屏/VirtualDisplay 输出长边上限（像素），0 表示不主动限制；大屏可降到 1280～1600 减轻每帧拷贝。修改后常在收起一级菜单时重建抓图链路。
inferenceMinIntervalMs连续两次调度推理的最小间隔（1～5000 ms）。
maxDetections后处理保留的最大检测数（上限与 UI 滑块一致部分为 1～10 档）。
inferenceConfidence置信度阈值（0.10～1.00）。
inferenceNmsIouNMS IoU（0.01～1.00）。
qnnAccelerationEnabled高通 QNN 偏好开关；非高通或会话侧会忽略；缺库时可关。
nnapiAccelerationEnabledNNAPI 加速开关。

6.2 画框与识别范围

  • boxStyleIndex、boxColorValue、boxLineWidthIndex、showClassNameEnabled、showConfidenceEnabled
  • recognitionRangePx、recognitionRangeVisible、recognitionRangeFilterEnabled、recognitionRangeHideBorder 等：中央识别区范围、是否仅保留范围内检测、是否绘制边线。

6.3 自动瞄准 / 压枪 / 扳机（存于同一配置）

包含 PID 参数（autoAimPid*）、触摸区域、偏移单位（绝对/百分比）、扳机模式（连点/连发）、开火间隔与首发延迟等。与二级菜单「自动瞄准」「自动压枪」「自动扳机」面板一致，保存时写入同一 ModelOverlayConfig。

JSON 中浮点数不允许 NaN/Inf，否则写入失败会导致整份配置保存失败。

七、ADB 与无线配对

在 ADB Tab 可查看连接状态、启动服务、配对相关日志等。无线配对可通过专用悬浮窗完成（标题「无线配对」）：输入配对端口（最多 5 位数字）与6 位配对码，使用内置数字键盘编辑；支持自动扫描配对端口提示（文案如「正在自动扫描配对端口…」）。

需悬浮窗权限方可显示该面板；若拒绝权限会引导到系统设置开启「显示在其他应用上层」。

ADB 与触摸链路因机型/ROM 差异较大，请以界面日志与官方说明为准；异常时可尝试重试或重启应用。

八、悬浮窗一级菜单（点击 / 长按）

屏幕识别运行时在悬浮层显示圆形入口与可展开面板。一级菜单分上排与下排按钮（见 ScreenCaptureForegroundService 中 upperActionItems / lowerActionItems）。

当一级菜单展开或二级配置面板（长按抽屉）打开时，会暂停推理，以减轻负载并避免配置与实时画框争用。

8.1 上排按钮

名称单击长按
显示方框 开关：是否绘制检测框（切换 enabled 并触发回调）。 打开二级面板：方框颜色、类名/置信度显示、线条粗细、识别范围相关开关与滑块等（与「显示方框」配置对应）。
手动触发 总开关（若实现中启用）。 打开二级面板：手动触发预设、区域、监视类型等（空列表时可新建配置）。
识别目标 在各类别间循环切换当前识别类别，并 Toast「当前识别目标：…」；若无类名则提示「当前模型没有可用类名」。 打开二级面板：从列表中点选目标类别。
模型参数 直接打开二级面板（与长按相同）。 打开二级面板：置信度、NMS、输入尺寸、推理速度、最大识别、QNN/NNAPI 等。
外设装备 开关。 打开二级面板（若有）。
其他设置 打开二级面板（当前占位文案可为「敬请期待」类提示）。 同上。

8.2 下排按钮

名称单击长按
性能监控 打开二级面板：勾选 FPS/CPU/GPU/延迟/温度等显示项及顺序。 不响应长按（设计如此）；仅单击进入配置。
同步找色 开关。 打开二级面板：HSV、取色流程、及与检测相关的置信度/NMS/最大识别等。
模板匹配 开关。 打开二级面板：模板列表、模板置信度、模板压枪/模板扳机开关等。
自动瞄准 开关。 打开二级面板：触摸区域、偏移、PID 全参数、无目标抬手帧数等。
自动压枪 开关。 打开二级面板：压枪单位（绝对/百分比）、压枪 X/Y 等。
自动扳机 开关。 打开二级面板：开火区域、扳机模式（连点/连发）、中心范围、开火间隔、首发延迟等。

二级面板底部通常有取消（关闭并可选恢复一级菜单）与确定；关闭时会持久化标量配置。若编辑的是「模型参数」，关闭前会将当前置信度/NMS 同步回推理服务。

九、二级配置面板（各菜单子项摘要）

9.1 「显示方框」

  • 方框颜色；显示类名；方框线条粗细。
  • 识别范围：总开关「识别范围」、仅不绘边的「不显示范围」、范围颜色、范围线宽、识别范围大小滑块（约 100～600 px）。

9.2 「模型参数」

  • 置信度（10%～100% 档）、NMS 连续滑块、输入尺寸步进、推理速度（ms）、最大识别（1～10）。
  • 高通机型显示「QNN加速」开关；以及「NNAPI加速」开关。

9.3 「识别目标」

展示当前模型可选类别列表；点选一项设为当前目标。无类名时提示「当前模型未加载类别名称」。

9.4 「性能监控」

选择展示指标及顺序（如 FPS、CPU、GPU、延迟、温度等，以界面为准）。

9.5 「同步找色」

HSV 相关、取色入口、清除；以及置信度/NMS/最大识别与检测后处理联动项。

9.6 「模板匹配」

新增模板、选择编辑中的模板、模板置信度步进、模板压枪/模板扳机开关。

9.7 「自动瞄准」

触摸区域框选、显示触摸点、随机触摸、偏移单位（绝对值/百分比）、偏移 X/Y、独立 XY PID 开关与全套 PID/滤波/平滑/积分限幅、无目标抬手帧数等；中间数值可弹出小数字键盘。

9.8 「自动压枪」

压枪值单位（绝对值/百分比）、压枪 X/Y。

9.9 「自动扳机」

开火键区域框选；扳机模式「连点 / 连发」；中心点范围、目标方框比例、开火间隔、首发延迟等。

9.10 「手动触发」

多组预设与监视区域（开火/识别等类型）、新建与重命名、区域编辑等；无配置时引导新建。

十、注意事项与常见问题

  • 权限：屏幕录制（MediaProjection）、悬浮窗、存储、蓝牙/位置（外设与旧版蓝牙扫描）等需按系统提示授予。
  • 横竖屏与分辨率：旋转或分辨率变化后，VirtualDisplay 与叠加层会按代码逻辑刷新；若截屏长边或物理分辨率变化，需等待菜单收起后链路重建。
  • 性能：推理间隔、截屏长边、模型输入尺寸、关闭不必要叠加显示均可改善卡顿与发热。
  • 配置未生效：确认保存路径可写；检查模型路径是否在 config.json 中只存一份键；多输出 ONNX 必须配置输出节点名。
  • 合规：请遵守当地法律法规及游戏/应用服务条款，合理使用辅助功能。
